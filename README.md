## 📖 Sobre o Repositório
Este espaço foi criado para documentar minha jornada de aprendizado e prática contínua com a linguagem Python. Para facilitar a consulta futura e manter o código limpo, decidi abandonar a estrutura sequencial (Exercício 1, 2, 3...) e organizar os scripts de forma **temática**. 

Como estudante de Análise e Desenvolvimento de Sistemas e desenvolvedor em constante evolução, utilizo este repositório para testar lógicas, resolver problemas algorítmicos e dominar as particularidades do Python, expandindo minha stack de tecnologias.
